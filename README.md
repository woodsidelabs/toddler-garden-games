# toddler-garden-games

Cordova-based app for young learners with voice and visual matching games for
numbers, letters, shapes, colors, and memory. Supports browser and Android.

## Playing in a browser

The games are plain static HTML/CSS/JS, so they can be opened directly from
`www/` — no build step required:

```bash
# any static server works; file:// will not, because of relative script loading
cd www && python3 -m http.server 8000
# then open http://localhost:8000
```

When hosted statically, `www/js/platform.js` provides the two things the
Cordova build normally supplies:

- the `deviceready` event the games wait for before wiring up click handlers;
- a `TTS` object backed by the Web Speech API, standing in for
  `cordova-plugin-neutts`.

Inside a real Cordova build, `platform.js` detects the native bridge and does
nothing, so the native TTS plugin is still used.

Speech uses the browser's installed voices; browsers without a voice engine
run silently, with the on-screen text and hint images carrying the game.

## Deploying to GitHub Pages

`.github/workflows/pages.yml` publishes `www/` on every push to `master`.
Enable it once under **Settings → Pages → Build and deployment → Source:
GitHub Actions**.

## Android build

```bash
npm install
npx cordova platform add android
npx cordova build android
```

`platforms/` is generated by those commands and is not tracked; it is rebuilt by
`cordova platform add android`. `plugins/` *is* tracked, because it vendors the
TTS plugin source.
